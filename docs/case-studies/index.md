# Case studies

These pages check real open-source projects on the platforms their build configuration names; a study that also looks beyond those platforms says so. Each study pins the project's revision and wheelgap version, records the target assumptions and commands, and explains the gaps and possible next steps. Results describe the package files available when the check ran; new uploads and lockfile updates can change them.

- [FastAPI: CPython 3.15 test dependencies across three platforms](fastapi.md)
- [Aider: Python 3.14 wheels on Linux and Windows](aider.md)
- [HERD: a 136-package service platform on ARM, Alpine and Windows on ARM](herd.md)
